# Platform adapter instructions

Read the [platform playbook index](../../docs/platforms/README.md) and the guide for the adapter you are changing. The playbooks define the job source, action order, screening and review boundaries, and the evidence required for each outcome.

Use the adapter’s own receipt rules. In particular, Cutshort confirms through the exact job’s new conversation, Wellfound verifies the persisted listing state, and HiringCafe hands off to an external ATS.
